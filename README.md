# Expense Tracker

A full-stack web application for managing personal income and expenses. Users can organize transactions by category, filter records, and track their monthly savings through a simple web interface.

## Features

- User registration and login
- Google and GitHub OAuth authentication
- Add, edit, and manage income
- Add, edit, and manage expenses
- Categorize transactions
- Filter transactions by date and category
- Monthly income and expense tracking
- Monthly savings calculation
- Responsive user interface

## Tech Stack

### Frontend
- HTML
- CSS
- EJS
- Tailwind CSS

### Backend
- Node.js
- Express.js
- Passport.js

### Database
- MongoDB
- Mongoose
